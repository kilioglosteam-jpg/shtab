# Штаб CS2

Турнирный календарь, стратбук и досье на соперников для команды.

- Сайт: GitHub Pages, файл `index.html`.
- Данные и скрины: Supabase (таблица `docs`, бакет `shots`). Вход по общему паролю команды (пользователь `team@shtab.app`).
- `.github/workflows/keepalive.yml` раз в три дня обращается к базе, чтобы бесплатный проект Supabase не засыпал.
